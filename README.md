# Тренажёр по матанализу — Telegram Mini App

Статическое приложение: `index.html`, `style.css`, `app.js` и `cards.json`. Сборка и сервер не нужны.

| Файл | Что это |
|---|---|
| `index.html`, `style.css`, `app.js` | само приложение |
| `cards.json` | карточки (их можно менять) |
| `check.html` | страница проверки `cards.json`: JSON и все формулы KaTeX |
| `.nojekyll` | пустой служебный файл для GitHub Pages, не удаляй |
| `matan_cards_p1-p23.json` | исходный файл, из которого скопирован `cards.json`; на сайт его загружать не нужно |

---

## Шаг 1. Загрузить сайт на GitHub Pages

1. Зарегистрируйся на <https://github.com> (если аккаунта ещё нет).
2. Справа вверху нажми **+ → New repository**.
   - **Repository name:** например, `matan` (адрес сайта будет `https://ТВОЙ_ЛОГИН.github.io/matan/`).
   - Выбери **Public**. Бесплатные Pages работают только с публичными репозиториями.
   - Нажми **Create repository**.
3. На странице нового репозитория нажми ссылку **uploading an existing file**.
4. Перетащи в окно файлы `index.html`, `style.css`, `app.js`, `cards.json`, `check.html`.
   Файл `.nojekyll` скрытый, и Проводник его может не показать. Без него сайт тоже работает, так что это не страшно.
5. Внизу нажми **Commit changes**.
6. Открой **Settings → Pages** (слева в меню).
   - **Source:** `Deploy from a branch`.
   - **Branch:** `main`, папка `/ (root)` → **Save**.
7. Подожди 1–2 минуты и обнови страницу. Вверху появится надпись *Your site is live at …*. Скопируй этот адрес.
8. Открой адрес в браузере. Приложение должно загрузиться, а без Telegram прогресс сохранится в браузере.
   Ещё открой `адрес/check.html`. Там должно быть написано «✅ Всё в порядке».

> Ссылка обязательно должна быть **https**. GitHub Pages даёт https сам, ничего настраивать не нужно.

## Шаг 2. Создать бота в BotFather

1. В Telegram найди **@BotFather** (у него синяя галочка) и нажми **Start**.
2. Отправь `/newbot`.
3. Введи имя бота, например `Матан тренажёр`.
4. Введи username. Он должен заканчиваться на `bot`, например `matan_kolok_bot`.
5. BotFather пришлёт токен. **Никому его не показывай.** Для этого приложения токен не нужен, сохрани его на всякий случай.

## Шаг 3. Привязать Mini App к боту

Удобнее всего сделать оба варианта.

### Вариант А. Кнопка меню (кнопка слева от поля ввода в чате с ботом)

1. В @BotFather отправь `/mybots` → выбери бота → **Bot Settings → Menu Button → Configure menu button**.
2. Отправь ссылку на сайт (`https://ТВОЙ_ЛОГИН.github.io/matan/`).
3. Отправь название кнопки, например `Учить`.
4. Открой чат со своим ботом. Слева от поля ввода появится кнопка **Учить**.

### Вариант Б. Отдельная Mini App со своей ссылкой

1. В @BotFather отправь `/newapp` и выбери бота.
2. Введи название и описание, загрузи картинку 640×360 (подойдёт любая).
3. GIF можно пропустить командой `/empty`.
4. Отправь ссылку на сайт.
5. Придумай короткое имя, например `train`. Приложение будет открываться по ссылке `https://t.me/matan_kolok_bot/train`.

> В новых версиях BotFather есть мини-приложение (кнопка **Open** в чате с BotFather). В нём те же настройки находятся в разделе **Mini Apps**, если команды не работают.

### Синхронизация прогресса

Прогресс хранится в Telegram CloudStorage. Он привязан к паре «твой аккаунт + этот бот», поэтому одинаково выглядит на телефоне и компьютере, если открывать приложение **через бота**. В обычном браузере прогресс хранится только в этом браузере.

## Шаг 4. Как обновлять `cards.json`

1. Отредактируй `cards.json` у себя на компьютере (например, в VS Code: он подсвечивает ошибки JSON).
2. На GitHub открой репозиторий → **Add file → Upload files** → перетащи новый `cards.json` → **Commit changes**.
   Старый файл заменится. Можно и так: открыть `cards.json` на GitHub → значок карандаша → вставить новый текст → **Commit changes**.
3. Подожди 1–2 минуты (вкладка **Actions** покажет зелёную галочку).
4. Открой `https://ТВОЙ_ЛОГИН.github.io/matan/check.html` и убедись, что ошибок нет. Если есть, страница покажет id карточки и проблемную формулу.
5. Перезапусти Mini App в Telegram (закрой и открой заново).

Что важно при правке:
- В JSON обратный слэш удваивается: в файле пишется `\\frac`, а KaTeX видит `\frac`.
- `id` у каждой карточки должен быть уникальным. **Прогресс привязан к `id`**: если переименовать id, карточка станет «новой».
- `type`: `definition` (определение), `theorem`, `lemma`, `property`, `corollary`. Всё, кроме `definition`, фильтр считает «теоремами».
- Если у карточки есть `proof_steps`, она попадает в режим «Доказательства» и может быть главным вопросом билета.

## Как устроены режимы

- **Карточки.** Карточки идут по порядку (или вперемешку). Нажимаешь «Показать ответ» и оцениваешь себя.
- **Доказательства.** Шаги доказательства открываются по одному. После последнего шага нужно оценить себя.
- **Повторение (Лейтнер).** «Не знаю» отправляет карточку в коробку 1, «С трудом» оставляет её на месте, «Знаю» переносит на коробку выше (максимум 5). Карточка выбирается случайно с весами 16/8/4/2/1 для коробок 1–5 (вес новых карточек 6), так что нижние коробки показываются чаще.
  «Повторить слабые» гоняет только карточки из коробок 1–2.
- **Билет.** 2–3 случайных вопроса, хотя бы один из них — теорема с доказательством. Ответы открываются после кнопки «Готов».
- **Фильтр** (кнопка справа вверху) действует на все режимы. **Поиск** ищет по названию среди всех карточек.
- **Прогресс.** Сколько карточек в каждой коробке и процент выученного по параграфам. Выученной считается карточка в коробке 4 или 5.

## Локальный запуск (необязательно)

Если открыть `index.html` двойным кликом, браузер не даст загрузить `cards.json`. Запусти простой сервер в папке проекта:

```bash
npx http-server -p 8099
```

и открой <http://localhost:8099>.
